Shipping a mobile dApp is still a month of plumbing.

Before the first screen renders you are wiring Expo, native modules, a wallet stack, and store assets.

Most teams never get past the scaffold.

“Works on my simulator” is not proof. Builds die on the device — in Gradle, at boot, or on the first screenshot.

Nobody verifies the last mile, because the last mile is expensive.

And a demo nobody can install isn't a submission. The APK is the deliverable.

Clock In rule: it has to run on a device.

One agent. Three surfaces.

You describe the app. Talon plans it, writes it, verifies it on hardware, and hands you a signed APK plus a dApp Store bundle.

Solana Mobile isn't a plugin. It's enforced.

THE AGENT IS REQUIRED TO

  • Use Mobile Wallet Adapter — useMobileWallet() + sendTransactions()
  • Build on @solana/kit program clients, devnet and testnet preconfigured
  • Sign in with a Solana wallet — ed25519 challenge, server verifies, never holds a key
  • Prove the handshake: test_wallet_roundtrip greps logcat for MWA evidence
  • Generate a dApp Store bundle alongside the APK

THE AGENT IS DENIED

  • @solana/web3.js — forbidden in the template and the skills, guarded in CI
  • wallet-adapter-react — “cannot run on the device, use MWA transact()”
  • …protocol-web3js transact calls
  • Seed phrases, key import, any private-key handling — the wallet holds all signing material
  • Phantom-only paths — evals disqualify @phantom/

15 embedded skills ship with the agent — solana-dev, wallet-mwa, seed-vault and dapp-store among them — and an @solana/kit import pulls the Solana skill automatically.

We re-derive your SKR payment from the chain.

STEP 01

Quote

The server states the price, pack size, mint and treasury. A price the client names is a price the client chooses.

STEP 02

Pay in-app

Hand-built TransferChecked over @solana/kit, signed through MWA in your own wallet. Mint never ships in the binary.

STEP 03

Verify

The server fetches the transaction itself on its own RPC and re-derives mint, recipient and exact amount.

STEP 04

Unlock

Credits grant release export. A fresh account hits the paywall.

VERIFIED PENDING · client retries, never re-sends REJECTED · HTTP 422
Fail-closed by construction. Wrong mint · wrong treasury · wrong amount · failed transaction → rejected. RPC unreachable → 502, no credits. Replay impossible — the signature is unique. Decimals come from the on-chain mint, never from config.
